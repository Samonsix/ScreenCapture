**ScreenCapture** Мощный и компактный инструмент для создания скриншотов в Windows.

## Возможности

- Скриншоты, аннотирование, скроллинг-скриншоты (длинные снимки), запись экрана (GIF/MP4), распознавание текста (OCR), распознавание QR-кодов.
- Пипетка с горячими клавишами для копирования цветов RGB (`Ctrl+R`), HEX (`Ctrl+H`) и CMYK (`Ctrl+K`).
- Рисование эллипсов, идеальных кругов (удерживайте `Shift`), прямоугольников, квадратов (удерживайте `Shift`), стрелок, нумерованных меток и т.д.
- Рисование кривых, прямых линий (удерживайте `Shift`), мозаики, ластика, текста.
- Изменение или удаление нарисованных элементов в любое время (наведите мышь на элемент).
- Отмена (`Ctrl+Z`), повтор (`Ctrl+Y`), сохранение в файл (`Ctrl+S`), сохранение в буфер обмена (`Ctrl+C` или двойной щелчок).
- Высокая скорость работы при низком потреблении памяти.
- Компактный размер, один исполняемый файл, установка не требуется, не требует сторонних DLL (кроме распознавания текста).
- Поддерживает различные аргументы командной строки для прямого запуска указанной функции.
- Поддерживает режим однократного запуска (процесс не остаётся работать в памяти после завершения).
- Поддержка нескольких языков.

## Компиляция

- Ветка main зависит от GUI-фреймворка [Ling](https://github.com/xland/Ling).
- Проект может быть скомпилирован с помощью Visual Studio 2026 (с установленным набором инструментов для разработки на C++).
- [2.4.25 (на основе D2D)](https://github.com/xland/ScreenCapture/tree/2.4.25) или [2.3.3 (на основе Qt)](https://github.com/xland/ScreenCapture/tree/2.3.3_qt) — предыдущие стабильные ветки.

## Командная строка

```
// Завершить процесс сразу после завершения съёмки.
> ScreenCapture.exe --auto-quit=true

// После выделения области не показывать панель инструментов, а сразу перейти к указанной функции:
// long — длинный снимок
> ScreenCapture.exe --enter=long
// video — запись экрана
> ScreenCapture.exe --enter=video
// ocr — распознавание текста
> ScreenCapture.exe --enter=ocr
// qr — распознавание QR-кода
> ScreenCapture.exe --enter=qr

// Аргументы можно комбинировать, например: без значка в трее, процесс выходит сразу после длинного снимка.
> ScreenCapture.exe --enter=long --auto-quit=true
```

## Плагин распознавания текста (OCR)

Встроенный офлайн-OCR ([PP-OCRv6](https://github.com/PaddlePaddle/PaddleOCR), small-модели со статическим выводом через ncnn, поддерживает китайский, английский и японский языки). Загрузка плагина больше не требуется.

- OCR запускается автоматически в фоне сразу после выделения области. Нажмите значок OCR на панели инструментов, чтобы войти в режим выделения текста: курсор превращается в I-образный над распознанным текстом, зажмите левую кнопку мыши и выделите нужный текст, затем скопируйте через `Ctrl+C` или контекстное меню. Нажмите `ESC` или значок ещё раз, чтобы выйти.
- Окно скрепления (pin) тоже поддерживает это: OCR запускается автоматически при создании скрепа; нажмите кнопку OCR на его панели инструментов, чтобы войти в режим выделения текста.
- Файлы моделей читаются из подкаталога `ocr` рядом с ScreenCapture.exe (det.param/det.bin/rec.param/rec.bin/dict.txt). Скрипт конвертации см. в `Tools/build_ocr_models.py`; модели также можно встроить в exe макросом `OCR_EMBED_MODELS` при сборке.
